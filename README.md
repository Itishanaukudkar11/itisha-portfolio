# Itisha Naukudkar - Portfolio

Next.js 14 + TypeScript + Framer Motion. Edit content in `lib/data.ts`, colours in `app/globals.css`.

## Run locally
npm install
npm run dev

## Deploy on Vercel
1. Unzip, push the folder to a GitHub repo.
2. vercel.com > Add New > Project > import the repo. Framework is auto-detected as Next.js.
3. Click Deploy.
